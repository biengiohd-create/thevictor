# THE VICTOR

Website thời trang tối giản với HTML, CSS và JavaScript thuần. Không cần bước build.

## Chạy website

Phục vụ thư mục gốc bằng một HTTP static server, sau đó mở index.html qua địa chỉ server.

## Chức năng

- Responsive trên điện thoại và máy tính
- Bộ lọc danh mục, tìm kiếm và sắp xếp giá
- Chi tiết sản phẩm, chọn kích cỡ
- Giỏ hàng lưu trên trình duyệt, thay đổi số lượng và xóa sản phẩm
- Thông báo rõ trạng thái sản phẩm minh họa

## Trước khi mở bán

Thay sản phẩm, ảnh, giá, thông số và thông tin thương hiệu bằng dữ liệu chính thức. Bổ sung liên hệ, chính sách giao hàng/đổi trả, quản lý đơn hàng và tích hợp thanh toán. Hiện chưa nhận đơn hoặc thanh toán thật.

Ảnh minh họa từ Unsplash; font từ Google Fonts. Khi vận hành chính thức nên dùng ảnh sản phẩm được sở hữu/cấp phép và tối ưu chúng ở máy chủ của cửa hàng.
